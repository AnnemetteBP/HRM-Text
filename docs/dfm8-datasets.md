# DFM8 Dataset Inventory

This is the exhaustive repository-level inventory of datasets with nonzero
coverage in the sampled DFM8 corpus. There is exactly one row per Hugging
Face dataset repository; no row represents an unexpanded repository group.

## Measurement and scope

- Contributions are measured from the six-epoch coverage report in
  data/show_analytics_dfm8.md. Per-epoch values are six-epoch means.
- Source rows/tokens describe the tokenized derivative visible to the DFM8
  sampler, not necessarily every row in the upstream HF repository.
- Sampled values include DFM8 caps and repetition.
- The report accounts for **70,479,308,606 tokens per epoch**. Direct sums
  from sampled epoch index arrays range from 70.479B to 70.480B.
- Canonical upstream IDs are used for sources restored through the
  consolidated Sapient mirror. Generated derivatives use their published
  schneiderkamplab repository IDs.
